数据流重定向:将标准输出或标准错误输出的数据写入到其他文件或设备
例子:
	1、将标准输出重定向
		ls -ld >(>>) 文件名 若目标文件已存在，则覆盖后再写入，若为>>则将新数据添加到目标文件的最后一行
	2、将标准错误输出重定向
		ls -ld 2>(>>) 文件名 若目标文件已存在，则覆盖后再写入，若为>>则将新数据添加到目标文件的最后一行
	3、将标准输出和标准错误输出重定向到不同文件
		ls -ld >文件A 2>文件B 则将错误输出重定向到B，标准输出重定向到A
	4、将标准输出与错误输出重定向到相同文件
		ls -ld >文件A 2>&1 意思是将标准输出重定向到A再将错误输出重定向到A的末尾
                /dev/null 是个黑洞文件可以吸收所有的信息，就像是垃圾站
	5、从文件中读取数据
		cat > file < 文件名 将文件数据写入到file中
		cat > file << "字符" 从键盘输入内容，当输入字符时敲回车直接结束

&&,||判断命令是否会执行，判断的依据就是上个命令执行后的返回值
例：command1&&command2||command3
该命令如此判断：首先执行command1，若执行成功，则执行command2，而command2与command3一般为可执行命令，故command2一定会执行成功，则command3就不执行
若command1执行失败，则执行command3。该命令适合条件判断，command1是条件，command2是command1为真时执行的命令，而command3是comman1为假时执行的名令。

管道命令 '|' 处理上一个标准输出的数据

cut -d '分隔符' -f n1,n2 以分隔符将数据划分成若干列，并输出n1,n2列
cut -c num- 显示num后的字符
grep '字符' 将含有该字符的行显示出来
grep -v '字符' 将不含有该字符的行显示出来

sort 默认以第一个字符进行排序
sort -c '分隔符' -k num 以num列进行排序 -n是以纯数字的形式排序

uniq 将重复的行变为一行，-c 统计有几个重复的，要与sort一起使用
wc 查询该文件有多少行多少字符
tee 双向重定向 可以将标准输出放入到文件中并能继续将同样的数据送到屏幕上处理

split -l num -[文件] 小文件的前缀 将文件划分为num行的小文件
split -b size -[文件] 同上
