type [-at] 可执行文件：该命令可以查询某个命令是否为bash内置的命令
                       -t 将结果以file(外置命令), alias(命令别名), bulitin(内置命令)呈现
                       -a 将PATH路径中包含该文件的路径列出，包含alias
ctrl+u 从光标出向前删除所有字符
变量的设置规则：
		变量名=变量内容
		变量名只能由数字获字母组成，开头不能是数字。
		若变量内容用双引号包围变量内容，则$可以保留原始特性，若用单引号包裹变量内容，就将所有特殊字符变为一般字符
		若要添加变量内容：变量名=变量名添加内容    ---相当于重新给变量赋值并保留了原来的变量内容
		若要在一串命令的执行过程中使用到其他命令的执行结果可以用$(命令)或`命令` 例:version=$(version) 也就是先执行的意思，比如ls -la $(cd /) 意思是先执行cd 然后执行ls
		取消变量:unset 变量名
		将变量变为环境变量，以供其他子进程使用:export 变量名
	
	技巧:可以将自己的工作目录用一个变量代替，这样就可以迅速进入到工作目录了
env:查看系统的环境变量及其内容
set:查看系统的环境变量，自定义变量，bash内置的变量
?:该变量的内容是上一个命令执行后的返回值，若执行成功则返回0，否则返回一个其他的数(该变量只与上一个执行命令有关)
export 自定义变量: 将自定义变量变为环境变量，供子进程使用
read [-tp] 变量A 从键盘输入给变量A赋值，最后得用换行结束 
	-p后面可以接提示符，-t接提供给用户输入内容的时间
declare [-aix] 变量名:声明变量 -i将变量声明成整型 -a将变量声明成数组 -x将变量变为环境变量 若不加参数，就显示所有变量的内容
	注:在bash中，变量默认为字符串类型，若不指定为整型，则a=1+2 就会被看做成声明了一个变量内容为1+2的变量，而不会进行数值运算
history 查询以往的命令 !!执行上一个命令 !num执行第num条命令 !com 执行最近以com开头的命令
命令运行的顺序:1、以相对/绝对路径执行命令 2、由alias找到命令执行 3、由bash内置的命令来执行 4、由$PATH这个变量的顺序查找到第一个命令来执行

bash的环境配置文件:bash在读完整体环境设置的/etc/profile并调用其他配置文件后，接下来则是读取个人配置文件~/.profile，该文件又会调用~/.bashrc文件,所以一般配置~/.bashrc
source 环境配置文件 ,在不重新登陆的前提下，直接读取配置文件
当是non-login shell时bash只会读取~/.bashrc环境配置文件

数据流重定向:将标准输出与标准错误输出分别传送到其他的文件或设备
	命令 > 文件名 将命令执行后的标准输出以覆盖的方式传送到文件中
	命令 >> 文件名 将命令执行后的标准输出以叠加的方式传送到文件中
	命令 2> 文件名 将命令执行后的标准错误输出以覆盖的方式传送到文件中
	命令 2>> 文件名 将命令执行后的标准错误输出以叠加的方式传送到文件中
	命令 > 文件A 2> 文件B 将执行后的标准输出以覆盖的方式传送到A,将执行后的标准错误以覆盖的输出传送到B
	/dev/null可以吸收标准错误输出，等价于直接丢弃
	命令 > A 2>>&1 将标准输出与标准错误输出传送到同一个文件
	cat > file 创建文件，并通过键盘输入内容
	
	输入重定向：
		cat > 文件A < 文件B 文件A从文件B中读取内容

命令A && 命令B 只有在命令A执行并且执行成功的时候才会去执行命令B 
命令A || 命令B 只有在命令A执行但执行失败时才会执行命令B
注:命令一定是从左往右执行，但有执行成功与否的区别，判断依据就是上一个命令执行后的返回值，?存储着这个返回值
典型的if else判断语句:A && B || C A执行成功，则执行B，反之，则执行C

管道命令:管道命令必须要能够将上一个命令的标准输出作为自己的标准输入
	 管道命令默认不处理标准错误输出，但可以利用2>&1 将标准错误输出定义为标准输出后再用管道

选取命令:cut,grep
cut [-dfc]讲一段信息的某一段取出来
	-d '分隔符' 将文件的每一行都按照分隔符划分成若干段，-f num 取出第num段
	-c n- 把每一行的第n个字符开始往后截取出来
grep [-v] '查找的字符' filename 在filename中将含有所要查找字符的行显示出来 -v则是将不含有所有查找的字符显示出来
去除空白行: grep [a-zA-Z] 

排列顺序:sort,wc,uniq
sort [-tkun] file/stdin 默认是对每行的第一个字符排序，并且默认是以文字形式进行排序
sort -t '分隔符' -k n 将每行按照分隔符分割然后按照第n栏进行排列 -n是按数字排序 -u将重复的行只显示一行
uniq [-ic] 将重复的行只显示一次 -i 忽略大小写，-c 进行计数 要与sort配合使用，得先排序再显示
wc 查询内容里的行数，字符数，单词数
